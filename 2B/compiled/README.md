# Installation - With Anaconda

```
> conda create -n trafficenv python=3.12.9
> conda activate trafficenv
> pip install -r requirements.txt
```

# Usage instructions
## Main project

```
> python main.py
```

## Data processing demonstration

Under `if __name__ == '__main__':`, uncomment each function to see
unique demonstrationsof how each piece of data was processed

```
> python data_processing_demo.py
```
